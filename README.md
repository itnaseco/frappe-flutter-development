# NASECO Frappe Delivery

An Agent Skill for developing Frappe and ERPNext backends with offline-capable Flutter field apps. It covers OpenSpec, shared UI, BPMN, DMN, and Mermaid documentation.

## Install

Run from your project with Node.js and npm available.

```sh
npx skills add itnaseco/frappe-flutter-development --skill naseco-frappe-delivery --agent codex claude-code kilo --copy --yes
```

Keep only the agent identifiers you use. Add `--global` to install across projects for your user. For other agents, substitute their identifier from the [supported agents list](https://github.com/vercel-labs/skills/blob/main/docs/agents.md).

Start a new session in the project. Use `$naseco-frappe-delivery` in Codex, `/naseco-frappe-delivery` in Claude Code, or ask Kilo Code to use the skill by name.

> Use the naseco-frappe-delivery skill in Specify mode. Design a Flutter field inspection that saves notes and photos offline and syncs to its Frappe site. Cover permissions, retries, duplicate uploads, and conflicts. Return a design only.

The skill includes its own references and uses approved specialist skills when available.
