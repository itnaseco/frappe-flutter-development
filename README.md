# NASECO Frappe Delivery

A Codex skill for developing Frappe and ERPNext backends with offline-capable Flutter field apps. It covers OpenSpec, shared UI, BPMN, DMN, and Mermaid documentation.

## Install

Run from your project with Node.js and npm available.

```sh
npx skills add itnaseco/frappe-flutter-development --skill naseco-frappe-delivery --agent codex --copy --yes
```

Add `--global` to install for your user across projects. Open a new Codex session and invoke `$naseco-frappe-delivery`.

> Use $naseco-frappe-delivery in Specify mode to plan an offline inspection workflow for our Frappe site and Flutter app.

The skill includes its own references and uses approved specialist skills when available.
